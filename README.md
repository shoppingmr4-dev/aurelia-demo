# AURELIA — Luxury Real Estate Website Concept

**Live demo:** https://shoppingmr4-dev.github.io/aurelia-demo/

AURELIA is a fictional luxury real-estate brand created as a portfolio concept. The project explores how a refined digital experience could present a curated collection of private residences through cinematic imagery, restrained typography, and a warm black-and-gold visual palette.

> **Portfolio concept:** AURELIA is not a real estate agency. The brand, residences, descriptions, and pricing references are fictional sample content created for demonstration.

## Project goals

- Create a premium first impression with a full-screen architectural hero image.
- Present a small collection of concept residences in clear, image-led cards.
- Use editorial sections to communicate atmosphere, architecture, and brand story.
- Provide clear paths through the page to the collection and enquiry section.
- Adapt the navigation and content layout for smaller screens.

## Design highlights

- Dark visual theme with warm gold accents.
- Large serif headlines paired with clean, minimal supporting text.
- Full-width hero imagery and rounded image cards.
- Subtle reveal and hover effects to add movement without overwhelming the content.
- Responsive layouts and a collapsible mobile navigation menu.
- Demo enquiry form that displays a notice; it does not send messages.

## Built with

- **HTML5** for page structure and content.
- **CSS3** for layout, responsive styling, typography, and transitions.
- **Vanilla JavaScript** for the mobile menu, scroll styling, section reveal effects, and demo form feedback.
- **GitHub Pages** for hosting the live demonstration.

## View the project

Open the [AURELIA live demo](https://shoppingmr4-dev.github.io/aurelia-demo/) to explore the page.

## Scope and transparency

This is a front-end design concept, not a functioning property listing or booking service. No real residences are offered, and the enquiry form is not connected to an email inbox or CRM. Images are loaded from external image URLs, so their availability depends on those providers.

## Possible customisation for a real client

The concept could be adapted with a client's approved branding, real property photography and details, final copy, and a verified contact destination. Any production integrations and content would need to be configured and tested for that client.
